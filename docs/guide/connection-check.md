# 연결한 뒤 실제로 확인하기

설치 목록에 보이는 것만으로 연결 확인이 끝난 것은 아닙니다. 새 대화에서 회사·센터·제품 이름으로 질문하고 실제 조회 결과를 확인해 주세요.

```text
태전 업무비서로 태전약품 전주센터에 레모나(하트캔) 재고 있어?
출처와 조회 시각도 알려줘.
```

1. Claude는 회사 조직 계정이 있으면 그 조직을, 없으면 개인 계정을 사용합니다. ChatGPT는 개인 계정입니다.
2. 처음 도구 사용을 묻는 창이 나오면 조회 내용을 확인하고 한 번만 허용해 주세요.
3. 답변의 제품·센터·출처·조회시각이 질문과 맞는지 확인합니다. 결과가 비었거나 오류가 났다면 재고 0으로 읽지 않습니다.
4. 이름이 비슷하면 회사명·제품 종류를 덧붙여 주세요. 회사와 거래처의 이름이 같을 때는 ‘회사 전체’인지 ‘등록 거래처’인지 알려주면 혼동을 줄일 수 있습니다.

## 매출을 물어볼 때

```text
내 등록 거래처인 [거래처 이름]의 [시작일]부터 [종료일]까지
[제품 이름] 매출 합계와 품목별 금액을 알려줘.
```

다음에는 이렇게 이어 물어볼 수 있습니다.

```text
그럼 같은 기간의 주별 추이도 보여줘.
```

제품코드나 내부 조회 참조를 외워 적을 필요는 없습니다. 자료가 일부만 확인됐거나 조회 기간이 일주일보다 짧으면 그 범위를 함께 확인합니다. 보존 원장을 다시 사용한 경우 최초 조회시각이 유지되므로 매번 방금 갱신된 값이라는 뜻은 아닙니다.

## 확인한 내용

아래 기록은 현재 로그인된 회사 사용자가 세 AI 계정 경로에서 확인한 결과입니다. 전체 직원·권한·기기와 모든 ERP 업무에 대한 인증을 뜻하지 않습니다.

| 경로 | 첫 Live 재고 조회 | 품목별 매출 집계 | 같은 원장 후속 조회 |
|---|---|---|---|
| ChatGPT 웹·개인 | 확인 | 확인 | 서버 주별 집계·같은 참조/조회시각 확인 |
| Claude 개인 Free | 확인 | 집계 도구를 지정한 진단 질문에서 확인 | 짧은 주별 후속 질문과 자동 원장 재사용 확인 |
| Claude 회사 조직 | 확인 | 등록 매출처 기준을 명확히 한 뒤 확인 | 짧은 주별 후속 질문·동일 조회시각 확인 |

Claude 개인 계정의 최초 일반 매출 질문은 원장 명세 도구를 먼저 선택해 집계 경로로 바꿔 확인했습니다. 같은 업무라도 모델이 선택하는 도구와 설명은 달라질 수 있습니다. 조회가 진행되지 않으면 승인 요청이 있는지 확인하고, 대상·기간을 분명하게 알려 주세요. 계속 막히면 사용한 앱·계정 경로·오류 문구를 알려 주세요.

Claude 조직 연결에서는 도구 목록 새로 고침 후 새 대화로 다시 검증했습니다. 기존 연결의 로그인 정보나 읽기 권한을 넓히지는 않았습니다. 이번 확인만으로 재설치가 필수라고 안내하지 않습니다.

실물 iOS·Android의 최초 연결부터 실제 조회까지는 검증하지 않았습니다. [휴대폰 안내](mobile.md)를 확인해 주세요.

재고는 회사·센터·품목을 지정해 실제 Live API 응답을 확인했습니다. 매출은 등록 매출처 한 곳·하루의 작은 범위로 품목 조건과 주별 계산·보존 결과 재사용을 확인했습니다. 여러 주의 실무 추이 분석이나 모든 품목·거래처의 전체성 검증을 완료한 것은 아닙니다. 직원별 권한과 AI 모델에 따라 도구 선택·확인 질문·처리 시간이 달라질 수 있습니다.
