# 휴대폰으로 사용하기

**먼저 설치할 때와, 연결 후 질문할 때를 나눠 생각하세요.** 휴대폰에서 PC 설치 메뉴를 똑같이 찾을 필요는 없습니다.

## Claude 모바일 — 같은 계정·같은 조직으로 이어 쓰기

1. 처음 연결은 [Claude 웹·PC 안내](claude-team.md)에 따라 마칩니다. 개인 무료 계정이면 [Free 안내](claude-free.md)를 따르세요.
2. iOS 또는 Android의 Claude 앱에서 **연결한 것과 같은 Claude 계정**으로 로그인합니다.
3. 조직 계정 사용자는 **희망-실천 리더십 등 연결한 같은 조직**을 선택합니다. 개인 Free에 연결한 경우에는 개인 계정을 선택합니다.
4. 새 대화에서 연결 목록을 확인하고 태전 업무비서를 사용합니다. 연결·추가 인증 요청이 나오면 본인의 회사 계정으로 완료합니다.
5. [첫 질문](first-question.md)을 보냅니다. 연결이 안 보이면 앱을 최신 버전으로 확인하고 계정·조직부터 다시 확인하세요.

Anthropic은 웹·데스크톱에서 연결한 서비스가 같은 계정의 iOS·Android에 제공된다고 안내합니다. 모바일에서 설치하는 기능은 베타이며 사용자 지정 커넥터의 기본 설정 경로는 웹·데스크톱입니다. 메뉴 위치는 앱 버전에 따라 달라질 수 있습니다. [공식 안내](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities)

## ChatGPT 모바일 — 계정에 사용 가능한 플러그인 확인

1. [ChatGPT 웹](chatgpt-web.md)에서 연결과 회사 인증을 마칩니다.
2. 휴대폰 ChatGPT 앱에 **같은 개인 계정**으로 로그인합니다.
3. 플러그인 목록에서 태전 업무비서를 찾아 새 대화에서 선택합니다. 앱 버전에 따라 목록을 여는 위치는 다를 수 있습니다.
4. 모바일에서 사용 가능한 연결이 표시되면 [첫 질문](first-question.md)을 보내고 실제 도구 응답을 확인하세요.

**‘Desktop only / 데스크톱 전용’ 플러그인은 모바일에서 사용할 수 없습니다.** 데스크톱의 Git 마켓플레이스에 설치했다고 모바일에도 자동으로 된다고 판단하지 마세요. 보이지 않으면 같은 계정인지, 웹에서 연결한 항목인지, 데스크톱 전용인지 먼저 확인합니다. 이 저장소를 일반 직원이 공개 플러그인 검색만으로 항상 찾을 수 있다고 보장하지 않습니다.

OpenAI는 모바일에서 계정에 사용 가능한 플러그인을 Chat·Work에서 쓸 수 있다고 안내합니다. 태전 연결을 실제 iOS·Android 앱에서 처음부터 끝까지 검증한 상태는 아니므로, 표시되지 않으면 아래 웹 경로를 사용하거나 지원 담당자에게 문의하세요. [공식 안내](https://learn.chatgpt.com/docs/plugins)

## 휴대폰만 있다면 — 회사 웹 업무비서로 바로 시작

[태전 웹 업무비서 열기](https://taejeon-core-llm-mvp.vercel.app/assistant)

1. Safari나 Chrome에서 위 링크를 엽니다.
2. 본인의 태전 회사 계정으로 로그인합니다.
3. 업무 요청 입력란에 제품명·센터명으로 질문합니다.

이 경로는 외부 AI 플러그인을 설치하는 절차와 별개입니다. 휴대폰 실기기별 키보드·인증·전체 조회 흐름은 미검증입니다. 연결에 문제가 있으면 [Core 연결 상태](https://taejeon-core-llm-mvp.vercel.app/me/mcp)를 확인하세요.

## 휴대폰으로 영상을 보고 있다면

**영상과 함께 전달된 설치 안내 링크를 누르세요.** 같은 휴대폰 화면의 QR을 다시 촬영할 필요는 없습니다. 큰 화면에서 영상을 볼 때는 QR을 휴대폰 카메라로 스캔해도 됩니다. 화면이 작으면 영상을 가로 전체 화면으로 보고, 실제 따라 하기는 이 안내를 한 단계씩 읽으며 진행하세요.
