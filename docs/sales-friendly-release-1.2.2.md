# 짧은 매출 질문과 재수집 방지 — 1.2.2

Core MCP 0.5.1과 함께 사용한다. 기존 서버 주소·인증·읽기 권한을 유지한다.

사용자는 “내 거래처 9월 노량 매출과 주별 추이”, “그럼 거래처별로도”만 요청한다. 등록 품목 확인, 생략된 대상·기간 연결, 조회 참조 관리, 완전성 검사는 업무비서와 서버의 책임이다. 내부 코드를 사용자에게 입력시키지 않는다.

- 같은 사용자·현재 허용 거래처·기간·회계 범위의 완료 원장은 24시간 내 자동 재사용한다. queryRef 누락이 재수집으로 이어지지 않는다.
- 명시적인 최신 재조회만 queryRef 없이 refresh=true로 수집한다. 구형 도구에는 지원하지 않는 인자를 보내지 않는다.
- 현재 연결의 규격을 이미 확인했다면 catalog/sources를 매 턴 재조회하지 않는다. 독립적인 품목·담당 확인은 함께 수행하고 합계·품목·추이는 한 호출에 묶는다.
- 기본 20초 대기 후 상태 또는 완료 결과를 반환한다. 상태만 확인한 뒤 결과를 다시 읽는 왕복은 필요한 경우에만 사용한다.
- 최초 ERP 수집은 직렬 호출과 제한 대기를 유지한다. 이 릴리스로 최초 수집 지연이나 모델 응답 지연이 모두 해결됐다고 주장하지 않는다.

1.2.1의 별도 시각화 작업은 포함하지 않았다. source/CI, main 병합, marketplace 갱신과 실제 호스트 업무 결과는 별도 배포 기록에서 확인한다.
